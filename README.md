# dsh-autopilot

Turn tickets into pull requests. Powered by DeepSeek Harness.

An open-source DeepSeek Harness plugin for running issue-driven AI Development Lifecycle (AIDLC) work on a VPS, with scheduled admission, a durable queue, resumable executions, spending controls, notifications, and a Web operations panel.

Planned providers: Jira or Linear for tickets; GitHub or Bitbucket for pull requests. Select providers through configuration and extend them with Cordis plugins.

**Status: specification only.** This repository contains implementation context; it does not yet ship an installable plugin. Features described in `docs/` are requirements, not claims of working software.

Start with [the implementation context](docs/README.md). It defines scope, ownership, behavior, and independently verifiable work packages.

Built for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Community project; not an official DeepSeek product.
