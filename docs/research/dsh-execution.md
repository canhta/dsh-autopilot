## Root lifecycle and continuation

[`ctx.agents.create({ sessionId, meta: { cwd }, agentOptions, setup })`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/core/agent/src/index.ts#L55) creates an owned root when `parentAgent` is omitted. `ctx.agents.resume({ resumeSessionId, agentOptions, setup })` loads persisted history before fresh scoped composition. Both return an `AgentHandle`; setup composes but never drives.

Drive the returned Agent with [`followup(UserMessage)`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/core/agent/src/runtime-types.ts#L175), using identified content/source. `cancel(cause, { keepInbox })` aborts current activity; default cancellation discards pending inbox work. `whenIdle()` observes root-driver/maintenance quiescence, not a particular prompt's completion or every descendant/process.

Reuse [`dsh-session-persistence`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/session/session-persistence/src/index.ts) and its selected provider. [`dsh-session-checkpoint-policy`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/session/session-checkpoint-policy/src/index.ts) flushes logged prefixes before applicable model/top-level-tool dispatch and subsequent steps. [`ctx.sessions.flush(session)`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/core/session/src/index.ts#L1131) returning `false` means no durability listener; requesting a flush alone does not prove persistence.

[`ctx.subagents.drainContinuableDescendants([root])`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/subagent/subagent/src/index.ts#L299) stops and releases retained descendant activations child-first. Its admission cutoff remains until that exact parent leaves the registry; later delegation requires reconstructed ownership, not reusing the drained live parent. Neither this method nor `whenIdle()` replaces each enabled tool/provider's shutdown obligations. Retain and dispose the root handle, flush required durable state, and verify the full composition's shutdown ordering.

The loop's [cold reconstruction](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/core/agent-loop/src/index.ts#L844) closes incomplete log records; it does not restore OS processes or reconcile external side effects. Autopilot still owns retained worktree identity and interrupted-action reconciliation, not a second Session store.

## Usage and spending

[`llm/stream`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/llm/llm/src/index.ts#L59) is the existing pre-dispatch waterfall. Loop requests are frozen/log-reconstructable: authorize without late mutation; configure output limits through supported request construction. Middleware must delegate with `next()` when allowing dispatch. Requests can carry `sessionId` and auxiliary purposes; coverage for retries, compaction, titles, children and unattributed calls needs explicit integration validation.

[`TokenUsage`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/llm/llm/src/types.ts#L141) separates uncached `inputTokens`, `cacheReadTokens`, `cacheWriteTokens` and `outputTokens`; optional totals/reasoning are not additional billable categories to sum blindly. [`dsh-token-meter`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/llm/token-meter/src/index.ts) provides `ctx.tokenMeter.measure()` for context pressure and registers the durable [`tokenUsage` projection](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/llm/token-meter/src/usage-projection.ts), including retry-aware folding. Reuse these observations instead of another Session-log usage fold; pressure estimates are not monetary upper bounds. [`dsh-llm-retry`](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/llm/llm-retry/src/index.ts) already owns agent request recovery.

The inspected facilities do not supply Autopilot's cross-run monetary reservations, pricing-version ledger, calendar spending windows or provider-account balance. Those business policies remain necessary; compose native hooks, usage projections and suitable [storage](dsh-platform.md#durable-storage-fit), without claiming every auxiliary request is represented in the conversation usage projection.
