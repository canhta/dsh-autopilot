# DSH engineering practice evidence

Inspected upstream `c291e7961a515f6d7af9304e7fd1d257929aef26` on 2026-09-11. Source-only review; no Autopilot tests or installed artifacts were exercised. This page records the provenance and limits of practices adapted in [engineering](../engineering.md); product requirements remain in specs.

## Portable practices and their evidence

| Area | What upstream establishes | External-plugin relevance or exception |
| --- | --- | --- |
| Loader identity and injection | Function plugins expose named `name/inject/Config/apply` without `default`; service plugins default-export their service class. Optional services use `ctx.get`, not undeclared property reads. [Package rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/AGENTS.md#L5). | Actual runtime behavior, not style. The [ACP postmortem](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/docs/postmortem/0001-acp-default-export-drops-inject.md#root-cause-1--export-default-apply-drops-the-plugins-inject-broke-sessionnew) shows hand-mounted tests missing both Loader export loss and foreign-fiber lookup failures. |
| Lifetimes | Registrations have effect ownership; dependent teardown belongs in one awaited sequence. Async state/idle is not one prompt's result. [Primer](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/docs/cordis-primer.md#L44), [defensive patterns](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/docs/defensive-patterns.md). | Quiescence uses the specific service's completion signal: current subprocess `done` means direct command exit, while `waitForExit` covers the managed range. Generic “kill then await done” advice does not prove descendants stopped. [Current subprocess meaning](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/subprocess/subprocess/README.md#L65). |
| Consumer-driven services | Service Definitions cover current consumers; tools/UI/transport details belong in consumers/providers. Every abstraction needs a current owner and need. [Package rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/AGENTS.md#L9). | Supports normalized tracker/code-host seams, not a package/interface per helper. A private capability closure can be preferable to a public single-caller method. |
| Authority and commit points | Decisions are enforced inside the operation, not only through schema omission or UI filtering. Derived state and notifications publish after successful commit; callback exceptions are contained. [Package rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/AGENTS.md#L14). | Relevant to direct Remote/tool callers and failed persistence. Cordis notifications are not an atomic transaction or durable outbox; Autopilot's storage requirements remain separate. |
| Types, durable data and model inputs | Branded cross-boundary identities; discriminated unions; runtime validation at config, queue, durable, process and wire inputs rather than redundant same-process checks. Model-visible inputs must be reconstructable from Session logs. [Root rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/AGENTS.md#L108). | Assigning a TypeScript type does not validate incoming ticket JSON. New custom Session events also create reader-compatibility obligations; this does not mandate adding events for presentation-only facts. |
| Test realism | Real Loader compositions, built consumer paths, disposal assertions, keyless replay and independently inspected world effects complement unit coverage. Mock expensive/nondeterministic inputs, not downstream behavior being proved. [Testing policy](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/docs/testing.md#prefer-the-real-implementation-over-a-mock). | An external packed-profile smoke additionally detects omitted assets/dependencies and accidental checkout imports. A recorded success message cannot prove a file change, PR identity or retained worktree. |
| Concurrency fixtures | Atomic temporary-resource allocation, explicit readiness, deterministic race barriers, restored globals and awaited cleanup; repeated runs or sleeps do not establish a race. [Reliability rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/.agents/skills/dsh-ci-test-reliability/SKILL.md). | Linux/VPS is the target, but tests may share ports, paths and processes even with isolated test workers. Upstream's full Windows/CI topology is not automatically Autopilot's support matrix. |
| Client presentation | Props/shares and framework hooks carry live data; components do not receive `ctx`. Feature values stay private; reusable values come from static libraries. Theme tokens and typed locale dictionaries own visual copy. [Client rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/client/AGENTS.md). | These constrain integration with DSH's renderer. They do not imply generic table/form exports or solve modal focus behavior; see [Web evidence](dsh-web.md). |

## Test facilities worth evaluating

Source package manifests declare public exports for `@deepseek-ai/dsh-loader-smoke`, `@deepseek-ai/dsh-llm-replay` and `@deepseek-ai/dsh-session-snapshot`. They are candidates for test-only reuse, not Autopilot runtime dependencies. The loader helper's production-profile fixture is explicitly repository-only. The snapshot entry imports Vitest and its ACP harvesting expects raw JSONL; the adapter and artifact path must fit the selected external profile before reuse is claimed. [Loader helper](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/test-support/loader-smoke/README.md#testing-a-shipped-profile), [snapshot export](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/test-support/session-snapshot/src/index.ts#L1), [replay manifest](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/test-support/llm-replay/package.json).

## Upstream mechanisms not inherited

The `@deepseek-ai` naming scope, workspace directory/tsconfig aggregates, central Web bundle edits, monorepo verifier scripts, exact 100%-per-file coverage policy, exhaustive platform matrix, Agent Notes and bilingual documentation machinery belong to upstream. Their useful outcomes can be adapted without copying their repository plumbing. Upstream's “inference is cheap here” policy is not spending authorization for Autopilot tests: live tests still require approved credentials/resources and explicit cost limits. [Package conventions](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/AGENTS.md), [test tiers and key policy](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/docs/testing.md#tiers), [documentation rules](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/docs/AGENTS.md).
